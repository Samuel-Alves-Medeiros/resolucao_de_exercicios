# resolucao_de_exercicios
Resolução de exercícios que demandam uma lógica de programação um pouco mais robusta.

## Mario quests
 - A pasta mario quests é dividida em 2 partes, a resolução das questões e o pdf de contexto  que contém as instruções da questão. As resoluções envolvem a criação de funções básicas do python manualmente, como o ".split()" e o ".len()", além de criar funções para decodificar cifra de césar e encontrar palíndromos.
